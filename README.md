# Paused idea: SVM evaluation of sEMG typing

**Status: paused; no new evaluation results are published here.**

This repository contains code and sample data from the [KeypressEMG source project](https://github.com/ANSLab-UHN/sEMG-TypingDatabase). An SVM hyperparameter comparison was considered as a follow-on idea, but the experiment was not completed. The source project's baseline results should not be read as results of a new study by this repository.

![Electrode placement diagram from the source project](images/electrode_positioning.png)

*Source-project illustration of the sEMG sensor placement.*

For the dataset description, setup instructions, baseline methods, and source attribution, use the [original KeypressEMG README](https://github.com/ANSLab-UHN/sEMG-TypingDatabase#readme) and the [full dataset record](https://borealisdata.ca/dataset.xhtml?persistentId=doi:10.5683/SP3/KV65VI). If this idea resumes, the new protocol, code, and independently verified results should be documented separately before presenting it as a completed project.
